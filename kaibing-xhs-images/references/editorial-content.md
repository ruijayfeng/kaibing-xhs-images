# 凯冰图文的内容表达

在分析、分页、提示词组装与验收时读取本文件。它补充白底编辑风格的内容制作规则，不替换已确认的身份图和八页视觉基准。原有布局的条目数、留白比例只作起点；页面是否讲清问题及手机阅读结果决定实际密度。

## 先写完整，再安排画面

为每个内页写一个读者问题，以及本页完整回答。按问题需要保留理由、具体例子、条件或可观察的结果；不把解释删成几个并列关键词。一个主要任务可以用连续段落完成，不等于只剩一句观点。

先区分来源叙述、作者判断与自己的延伸。只用材料支持的事实；表达不确定性和未完成部分。观点类内容可用同一案例推进“发生了什么 → 为什么 → 有什么影响”，避免每页重新开一个支线。

不设每页统一字数、条目数或正文行数上限。需要清单时用清单，需要因果解释时保留段落，需要证据时给截图留位置。内容太多先删重复，再按问题拆页；不要先缩小字号或为了留白删掉必要解释。正文已由用户确认时，保持其含义，新增说明先在本轮文案中记录。

## 决定文字和图像各自负责什么

分页记录同时写明“正文要解释什么”和“画面让读者看见什么”。使用连续场景、对话、选择、对比、流程、关系标注、真实证据或模板；不把同一句话同时重复成标题、卡片和插画标签。

| 页面任务 | 画面承担的信息 |
|---|---|
| 解释痛点或限制 | 触发条件、发生的事件、人物的受阻状态或后果 |
| 比较与选择 | 选项差别、选择动作及对应结果 |
| 机制或关系 | 谁连接谁、步骤顺序、方向与边界 |
| 实际案例与结果 | 原始截图中支持结论的区域，配必要中文说明 |
| 操作与模板 | 可执行步骤、输入内容、检查点及完整可用文本 |

页内允许正文在图上方、下方或侧边自然展开。标题、正文与图像形成阅读顺序，不必每页套相同大标题、模块框和插画位置。结尾完成当篇的总结、问题或可用模板；当前不自动追加固定品牌尾页、关注按钮或通用口号。

## 标题层级与密度

封面保持大标题；内页标题贴近正文的阅读尺度，默认单行，过长时自然换行或精简措辞，不能为填满宽度而放大。标题与正文各只指定一种尺度和换行要求，避免提示词里互相冲突。

1080px宽的排版起点可参考：内页标题约44–56px，正文约36–42px，次要注释约26–30px；标题通常约为正文的1.2–1.4倍。数值不是硬性保证，最终以字形体量和360px宽预览为准。整页生成中文字形由模型绘制，不能宣称像真实字体一样精确控制字号。

正文采用正常字重、清楚行距和段落间距，只强调帮助定位判断或步骤的短语。缩小标题不等于缩小全部文字；留白用于区分内容层级，不以空白比例或字数少作为完成标准。

## 人物场景的语义检查

具体身份与参考加载遵循[凯冰集成规则](kaibing-integration.md)。解释场景除移除人物测试外，还须检查：人物正在经历或选择什么，动作、目光和对象如何让读者看见本页的关系。

仅“拿着纸”“看着屏幕”不足以证明解释成立；需要时呈现被阻断的去路、相互矛盾的状态、被选中的选项或可见后果。人物可以是体验者、提问者、选择者或旁白，不默认成为技术人员、内容助理或后台操作者。

动作需要接触时，检查握持、指尖与对象的实际接触、身体重心和目光方向。再检查场景含义是否相符：选中的分类应对应展示结果，成功与失败应指向不同条件，箭头应有明确来源和去向。步骤、截图与证据页可不放人物。

## 证据与制作方式

保留真实截图原文件。只在需要时移除外部无信息白边、截取关键区域并等比放置，记录范围，不改写界面内容或把生成界面当证据。源图细字无法在手机上阅读时，用局部、关键行或准确中文说明承担解读，并在验收中记录清晰度限制。

以整页生成作为默认已测试路径。证据页需要准确保留截图和文字时，可直接用原始素材与可用真实中文字体进行一次整页排版；需新插画且文字必须确定时，先生成适配构图的无字母版，再整体排版。记录实际字体、完整文案与素材位置，不在已生成文字上逐块盖补丁，不为此安装新后端。

真实结果、来源案例、个人推论、概念示意和待补素材的身份记录在outline与生成记录中，并以准确正文区分。正式画面不自动出现“概念示例”“非实际产品测试”等制作说明；必要来源署名仍可保留。

## 验收完成条件

- 内容：本页能完整回答规划的问题，重要条件、理由或例子没有被装饰或短口号替代；整套前后衔接。
- 图文：画面实际承担所记录的信息，图中状态、选择结果、箭头方向和人物动作符合正文。
- 阅读：封面约240px、内页约360px宽实际查看；正文及关键标签可读，标题不过度挤占信息，逐字核对中文与页脚。
- 来源与交付：证据归属、素材限制和制作方式记录清楚，原图与候选保留。技术检查通过不等于用户确认了新视觉基准。

本规则来自2026-10-06的解释型内页优化与新文章五页制作验证；沿用“凯冰白底编辑图文v1”的色彩、身份和已确认样例，不把本次测试成果自动列为新的已确认样例。
