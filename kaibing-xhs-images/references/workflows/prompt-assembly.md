# 凯冰整页提示词组装

## 先读什么

读取 `references/kaibing-integration.md`、`references/approved-style.md` 和 `references/editorial-content.md`。按页所选布局读取 `references/elements/canvas.md`；选择原有风格时读取 `references/presets/<style>.md`，自定义风格从项目 EXTEND.md 读取。已确认的项目偏好优先于自动匹配。`kaibing-editorial` 沿用 minimal 的布局兼容性，并以 EXTEND 中的字体、色彩和装饰规则覆盖该预设相应项。

## 逐页组装

1. 从 outline 取读者问题、完整文案、图文分工、布局与素材来源；为标题、正文和注释指定一种一致层级，尺度按内容表达规则安排，不让内页标题填满整行或占据封面体量。按已确认文案出字，保留条件、例外和不确定性，不自行添加解释段落。
2. 从所选风格提取色彩、视觉元素和字形，从布局提取信息组织关系。不要将样例的文案、截图或霓虹背景带入当前页。
3. 先设计标题、内容与主视觉之间的整体关系，确定角色有无、所经历的事件、目光和接触点；写明图中状态、选项与结果如何对应正文。将一张凯冰身份参考和可选风格参考分开标注。
4. 按集成指南选整页生成或真实字体制作。整页生成包含准确文案；真实字体分支需新插画时，图像提示词留出匹配全部文案的区域并保持无字。仅使用真实截图的证据页直接保存完整排版说明，不额外生成截图。整体排版另存文字、字体与素材位置记录。
5. 保存提示词文件后，按当前工具的实际参数传入已核实的参考图。新图使用 `referenced_image_paths`，不凭路径文本假装已加载；不添加特定后端口号或接口不存在的参数。

## 提示词文件结构

frontmatter 是本地生成记录格式，不是上游 EXTEND 的配置 schema。路径在运行时填入本轮实际绝对路径。

```yaml
---
page: 1
page_count: 6
position: cover
style: kaibing-editorial
layout: sparse
render_mode: full-card
character: q
references:
  - role: identity
    path: /absolute/path/to/refs/kevinbee-q.png
  # 可选：本轮实际存在且已确认的成品风格图，不凭空写入
---
```

人物缺席时记录 `character: none`，不传身份图；若传封面风格参考，明确只继承视觉系统、禁止复制其中的人物或图中文字。真实素材只在确有文件且本页需要时记录，说明保持原样及插入区域。

提示词正文只保留影响本页的内容：

```text
用途：小红书封面 / 内页 / 结尾。
画布：严格 3:4 竖版，最终 1080×1440，白底，无外框，完整保留人物和正文。
页面任务：本页要让读者理解或看见的具体内容。
整体构图：标题、正文、人物和一个核心对象如何形成阅读路径；各区域的体量关系和留白。
风格：从本页选定风格与项目偏好提取的规则。
信息结构：按 sparse / balanced / comparison / flow / list 等所选布局组织，页内标题层级与正文阅读顺序。
输入图像用途：按实际传参顺序标明身份图、风格图、真实素材。身份参考负责身份和 Q 版比例，姿势按当前事件重新设计。
人物：出现与否，凯冰经历或选择什么，具体动作、表情、目光与接触点，以及动作帮助理解什么。
文案：列出准确主标题、完整段落或可用清单与短注释原文；保留阅读顺序，没有内容的层级省略。
页脚：根据署名设置及本轮页序写准确的作者与页码。
真实素材：准确来源、原样保留区域及清晰度限制；区分实际结果与解释场景，不自动把内部制作分类打印成测试标签。
检查重点：完整回答、身份、文字、动作接触、状态与结果对应、箭头方向和手机阅读要求。
```

真实字体分支用 `render_mode: real-font`；需要生成插画时，图像提示词保留空间与构图但不绘制正文、标题或署名。直接使用原素材时无需图像生成调用。保存实际字体、文案、文本框、素材位置与最终图片；不把无字母版作为完成的有字卡片交付。

## 生成顺序与一致性

先出一张样张，复用当前任务确认。已确认封面可作为后续页面的风格锚点；每张有人物页仍直接传入凯冰 Q 身份图。若先确认了内页，以内页暂作风格参考，封面确认后再采用封面。不同页面可改变结构、人物位置和大小，只继承统一的视觉系统。

只在用户明确选其他配色时读取对应 palette；默认使用项目白底、暗红与冰蓝。其他风格的手写字、纸纹、装饰与极端色彩不自动加入默认编辑风格。

生成前核对：准确文案已保存、参考实际存在且已查看、工具支持传入参考、署名与页序正确、提示词没有相互冲突的画幅或人物形态要求。
